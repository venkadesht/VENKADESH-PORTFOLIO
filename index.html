Things I've built

Amazon EKS Deployment with AWS Fargate & ALB Ingress
Kubernetes · AWS

A fully serverless Kubernetes deployment on EKS using Fargate — no worker nodes to manage. External traffic routed through an AWS Application Load Balancer via Kubernetes Ingress.

  • Deployed multi-component app using eksctl, kubectl, and Helm with Fargate profiles for serverless compute.
  • Configured AWS Load Balancer Controller via Helm + IRSA to automate ALB provisioning.
  • Set up Prometheus and Grafana dashboards for real-time workload observability.
  • Eliminated manual node management entirely — scaling handled by Fargate automatically.

CI/CD Pipeline for Containerized Python Application
CI/CD · GitOps

End-to-end pipeline automating everything from a git push to a live Kubernetes deployment — cut release time from ~15 minutes down to under 3 minutes.

  • GitHub Webhooks trigger Jenkins on every push, eliminating all manual build steps.
  • Docker images built, tagged, and published to Docker Hub automatically in the pipeline.
  • ArgoCD syncs deployment manifests from Git for GitOps-style continuous delivery.
  • Rolling updates to Kubernetes ensure zero-downtime releases; rollout health verified with kubectl.
